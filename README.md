One line, max 200 characters — a brutally honest, funny error message that says what actually broke.

> Error 418: I'm a teapot, and honestly, so is this code — nothing works, nobody knows why, and the last person who understood it quit.

133 characters. Run `main.ts` with Node and it writes exactly that line to `entry.txt` in the output directory.
